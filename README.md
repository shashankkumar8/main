## Run locally

No build step or dependencies are required. Open `index.html` directly, or run:

```bash
python -m http.server 8080
```

Then open http://localhost:8080.

## Deploy

The repository is configured for a Render Static Site:

- Build command: `echo "Static portfolio — no build step required"`
- Publish directory: `.`
- Branch: `main`
